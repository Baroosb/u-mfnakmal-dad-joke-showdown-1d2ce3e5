One dad joke, at most 200 characters: the whole entry for the Dad Joke Showdown. The joke lives in `entry.txt`; `main.py` copies it byte-for-byte to the output as `/output/entry.txt`. The joke was picked by a candidate tournament judged pairwise by the bounty's own judge model against the published judge brief.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
